# 해동삼국기 테마 스타일 가이드

이 문서는 `해동삼국기 · 삼국의 유산`의 화면과 생성 에셋이 같은 시각 언어를
유지하도록 하는 기준이다. 게임 로직이나 데이터 ID를 화면 코드에 직접 넣지
않으며, 모든 세력·지역·인물 표현은 시나리오 데이터에서 공급한다.

## 색상

| 용도 | 색상 | 사용 규칙 |
| --- | --- | --- |
| 화면 바탕 | `#171612` | SafeArea와 전체 배경 |
| 패널 | `#29241B` | 목재·흑갈색 패널의 기본색 |
| 청동 테두리 | `#9A7138` | 프레임, 구분선, 비활성 버튼 |
| 금색 강조 | `#F0D59A` | 제목, 선택 상태, 핵심 수치 |
| 보조 금색 | `#B29A71` | 설명, 보조 라벨, 비활성 텍스트 |
| 성공 | `#6FA56B` | 등용 성공, 승리, 긍정 변화 |
| 경고 | `#C47A54` | 부족한 자원, 위험 상태 |
| 적대 | `#A14C45` | 적 세력, 공격 가능, 패배 |

세력 색상은 지도 영토와 깃발에만 적용한다. 배경 지도 자체를 세력 색으로
덧칠하지 않으며, 선택 효과는 세력 색과 독립적인 금색 외곽선으로 표시한다.

## 명칭과 숫자

- 정식 제목은 `해동삼국기`, 부제는 `삼국의 유산`으로 고정한다.
- 시나리오 ID는 `scenario_{world}_{year}` 형식, 회귀용 가상 시나리오는
  `generic_prototype`을 사용한다.
- 성·지역 이름은 한글 1~3글자를 우선한다. 세력 이름은 2~5글자 범위를
  권장한다. 장수는 역사 인물의 `displayName`을 사용한다.
- 연도는 `서기 642년` 형식으로 표시하고, 월은 `1월`처럼 숫자와 월을 붙인다.
- 자원 숫자는 천 단위 쉼표를 사용한다. 금·군량·병력은 단위를 반복해 붙이지
  않고 라벨에서 한 번만 표시한다.
- 능력치와 충성도는 0~100 범위, 병력·자원은 음수가 되지 않도록 표시한다.

## 타이포그래피와 레이아웃

- 제목은 굵은 한글, 금색, 짧은 행으로 표시한다.
- 본문은 보조 금색을 사용하며 긴 문장은 2줄 이내로 줄바꿈한다.
- 주요 조작은 하단 한 손 영역에 배치하고, SafeArea 안쪽에서만 렌더링한다.
- 카드와 버튼은 같은 청동 테두리·모서리 반경·상태 색상을 공유한다.
- Dynamic text scaling에서 겹침이 생기지 않도록 고정 폭 텍스트 대신
  `Expanded`, `Flexible`, `FittedBox`를 우선한다.

## 아이콘과 이미지 레이어

- 금·군량·병력·민심·개발·치수·성벽은 동일한 금색 아이콘 계열을 사용한다.
- 성·깃발·초상화·선택 효과·지역 경계는 서로 독립 레이어로 렌더링한다.
- 생성 이미지에는 글자·로고·깃발·성을 포함하지 않는다. 해당 요소는 데이터와
  Flutter/Flame 레이어에서 표시한다.
- 스프라이트는 투명 PNG를 기본으로 하며, 흰색 또는 검은색 매트가 발견되면
  적용하지 않는다.
- 초상화는 같은 세로 비율과 조명 방향을 유지하고, `portrait_{officerId}.png`
  규칙으로 등록한다.

## 상태 표현

| 상태 | 표현 |
| --- | --- |
| 선택됨 | 금색 외곽선 또는 은은한 금색 후광 |
| 이동 가능 | 낮은 대비의 청색 셀 강조 |
| 공격 가능 | 낮은 대비의 적색 셀 강조 |
| 비활성 | 채도와 대비를 낮춘 청동색 |
| 성공 | 녹색 결과 문구와 금색 수치 |
| 실패·위험 | 적색 문구, 과도한 깜빡임은 사용하지 않음 |

## 금지 사항

- 원작의 이미지·폰트·문구·맵·초상화를 복제하지 않는다.
- 임시 선, 디버그 도형, 가상 이름을 한국 시나리오의 출시 화면에 남기지 않는다.
- 화면별로 임의의 금색·갈색을 새로 만들지 않고 이 규칙 또는 공통 토큰을 사용한다.
