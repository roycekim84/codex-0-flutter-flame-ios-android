# Realm Ledger — 게임 규칙

현재 프로토타입은 가상 세계의 6지역·3세력·18장수로 구성된 월 단위 전략게임이다. 참고 화면 기반 목표는 지역 상세와 장수 명령을 중심으로 한 고전 군주제 전략게임의 전체 루프다.

- 1턴은 1개월이다.
- 플레이어는 장수를 선택해 내정·인사·군사·외교·첩보 명령을 배정하고 턴을 종료한다.
- 월말에 영지의 토지와 개발도에 따라 금·군량을 얻는다.
- AI 세력도 플레이어와 동일한 명령 API와 월말 흐름에서 제한된 자원으로 행동한다.
- 최종 목표는 모든 주요 지역을 점령하는 것이다.

전투·외교·첩보·포로·월말 보고는 단계적으로 추가하며, 모든 화면은 데이터 기반 GameState를 공유해야 한다.
