## 참고 화면 기반 재정렬

현재까지는 기술 수직 슬라이스를 확인한 단계다. 다음 우선순위는 화면 장식이 아니라 명령 시스템과 지역 상세 중심의 플레이 루프다.

- [ ] Phase A: 타이틀·시나리오·군주 선택·월 시작·지역 상세·장수 상세
- [x] Phase B: 장수별 월간 명령, 탐색·등용·포상·추방·태수, 월말 보고
- [x] Phase C 일부: 출병 준비·다부대 편성·지형 전투·포로 처리
- [ ] Phase D: 외교·첩보·정보 제한·이벤트·멸망·통일

각 Phase는 화면이 존재하는 것만으로 완료하지 않는다. 명령이 GameState를 바꾸고, 로그·저장·AI·테스트에 반영되어야 완료한다.
