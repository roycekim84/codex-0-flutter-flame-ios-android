# 해동삼국기 테마 전환 로드맵

## 1. 전환 목표

현재 게임의 핵심 시스템은 유지한다.

```text
기존 GameState / GameCommand / GameEngine / BattleEngine / 저장 / AI
                              ↓
                         해동삼국기 데이터팩
                              ↓
       한국 삼국시대 세계관의 UI·지도·인물·전투 연출
```

이번 작업은 게임을 새로 만드는 것이 아니라, 검증된 전략게임 엔진에 한국 삼국시대의
세계관과 시각 언어를 입히는 테마 전환이다.

- 정식 제목: **해동삼국기**
- 부제: **삼국의 유산**
- 기본 무대: 고구려·백제·신라·가야계 세력과 주변 세력
- 기본 시간: 서기 연도·월 단위
- 기존 가상 데이터: 개발용 시나리오로 보존
- 한국 시나리오: 별도 데이터팩으로 추가하며 엔진 코드는 수정하지 않음

## 2. 절대 유지할 기능 경계

다음 시스템은 테마 교체와 독립적으로 유지하고 회귀 테스트한다.

- 월 단위 턴 진행과 월말 정산
- 지역 점령, 인접 이동, 출병과 전투 진입
- 금·군량·병력·민심·개발·치수·성벽
- 군주·태수·장수·충성도·포로 상태
- 탐색·등용·포상·추방·장수 이동
- 외교·첩보·정보 제한
- BattleEngine의 육각 격자, 이동·공격·돌격·화공·협공·정보·대기·퇴각
- AI의 GameCommand 사용, 승리·패배·통일 처리
- AUTO 및 1~5 저장 슬롯, saveVersion과 migration

UI가 바뀌어도 UI가 GameState를 직접 수정하지 않는 구조는 유지한다.

### Phase 7 — 이미지 생성 및 적용 파이프라인

이미지 생성은 화면마다 필요한 에셋을 분리 생성하고, 생성 결과를 그대로 배경에
합성하지 않는다. 모든 스프라이트는 투명 배경 여부를 검수한 뒤 적용한다.

#### 생성 우선순위

1. 세로형 세계 지도 배경: 성·문양·텍스트가 없는 순수 지형 지도
2. 대·중·소 성 스프라이트: 투명 PNG, 정면/사선 공통 스타일
3. 세력별 깃발과 문장: 투명 PNG, 동일 캔버스 크기와 기준점
4. 군주·장수 초상화: 어깨 위 초상, 동일 조명·테두리·비율
5. 타이틀·시나리오·탐색·외교·이벤트 배경 일러스트
6. 전투 지형 배경·부대 스프라이트·세력별 전투 깃발
7. 금·군량·병력·민심·성벽·치수·외교·첩보 아이콘
8. 패널 프레임·버튼·탭·상태 효과·승리/패배 장식

현재 적용 완료: 신라·고구려·백제 전용 깃발 3종을 투명 PNG로 생성하고,
한국 시나리오의 `bannerAssetId`와 세계 지도·지역 상세·세력 정보 UI에 연결했다.
일반 프로토타입 시나리오는 기존 스프라이트 스트립으로 자동 폴백한다.

- [x] 2차 기준 20명: 흠돌·무력·도침·구형왕·장보고 초상화 생성·연결

#### 생성 규칙

- 원작 그래픽·초상화·맵·폰트·문구를 복제하지 않는다.
- 역사 실존 인물은 이름과 역사적 맥락을 참고하되, 초상화는 새로 생성한 독자 이미지로 제작한다.
- 생성 프롬프트에 `no text`, `no logo`, `transparent background`를 명시한다.
- 배경 지도에는 성이나 깃발을 그리지 않고 Flutter 레이어에서 배치한다.
- 지도·성·깃발·선택 효과·지역 경계·UI 패널을 각각 독립 레이어로 유지한다.
- 모든 생성 에셋은 실제 적용 전 축소 화면과 확대 화면에서 가장자리·흰 배경·후광을 검사한다.
- Flutter Web과 모바일에서 동일한 기준점으로 보이도록 앵커 좌표를 데이터화한다.

- [ ] 흰색/검은색 매트 잔여물 확인
- [ ] 이미지 내부에 생성된 글자·성·깃발이 없는지 확인
- [ ] 세력 색상 변경 시 배경 지도 색이 오염되지 않는지 확인
- [ ] 선택 성 후광과 선택 지역 경계가 서로 중복되지 않는지 확인
- [ ] Web 세로 화면에서 화면 밖으로 잘리지 않는지 확인

## 4. 권장 구현 순서

```text
Phase 0
  ↓
한국 데이터팩 + 공통 UI 토큰
  ↓
세계 지도와 군주 선택
  ↓
지역 상세와 월 진행
  ↓
인사·군사·외교·첩보 화면
  ↓
전투 결과와 확장 화면
  ↓
전투 에셋·한국식 연출
  ↓
통일까지 전체 QA
```

한 화면이 완료되었다고 판단하는 기준은 정적 화면이 보이는 것이 아니다.

1. 한국 데이터가 표시된다.
2. 버튼이 실제 `GameCommand`를 발생시킨다.
3. `GameState`와 로그가 변경된다.
4. 다음 화면으로 자연스럽게 전환된다.
5. 저장·불러오기 후 상태가 유지된다.
6. 세로 화면과 큰 글자에서도 깨지지 않는다.

## 5. 완료 조건

- 모든 기본 화면의 제목·문구·데이터가 해동삼국기 기준이다.
- 한국 시나리오에 실존 군주·장수 약 100명이 등록되어 각자의 초상화와 연결된다.
- 게임 시작부터 통일까지 한국 시나리오 한 판이 완료된다.
- 지도 배경과 성·깃발·경계·선택 효과가 분리되어 세력 점령에 따라 갱신된다.
- 고구려·백제·신라·가야계 세력의 색상과 문장이 서로 구분된다.
- 기존 가상 시나리오를 선택해도 엔진 회귀가 없다.
- 이미지 생성 에셋에 흰 배경, 임시 선, 생성 텍스트가 남아 있지 않다.
- Web 배포와 Flutter 테스트가 모두 성공한다.
